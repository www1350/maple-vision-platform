## 目标与接口

在已有视觉观测之后增加有界对象追踪、字段来源/置信度/有效期及显式未知状态，
再通过独立任务候选、优先级仲裁、计划、动作意图、顺序授权执行和效果验证驱动同一模拟器。
真实动作入口只接收已授权意图，不读取图像或动态真值。紧急生存任务可抢占普通任务，
取消、过期、重复或未注册意图必须拒绝；命令被接受不能充当效果成功。

原 `VisualAgent` 与 schema1 默认路径保留兼容。显式选择结构化运行时才使用新路径；
所有新配置随 schema2 运行包保存，禁止依赖缺省字段猜测模式。

## 证据与验收

1. 每个采集帧只执行一次状态更新，包含暂停时的画面及最后一帧。保留轨迹不等于重新看见对象。
2. 分别保存原始观测、派生状态、任务候选/选择、计划/意图、调度授权和真实执行回执。
3. 预算退出记录最终状态和未执行的策略阶段；不能补造终止决策。
4. 动作重放核查意图与请求动作、时序、回执及故障配置。实际重新推理还要逐帧重建整个状态/任务链。
5. 全部三职业、内置/外部地图、正常和预期故障、重放、状态/配置篡改反例分别验收。
6. 保存旧回归、隔离安装及准确提交的 Ubuntu/Windows/native CI 结果；失败必须保留和修复。
