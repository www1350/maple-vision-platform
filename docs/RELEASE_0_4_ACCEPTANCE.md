# v0.4 外部地图包与可移植验证验收

**本地工程、独立三地图验证与隔离安装已通过；准确提交的远端 CI 另行记录。** 本轮把外部地图内容接入已有离线平台，未训练新研究模型，未改变 v0.3 失败候选及其关闭分支。总体方案见 [FINAL_PLAN.md](FINAL_PLAN.md)，执行步骤与条件见 [V0_4_PLAN.md](V0_4_PLAN.md) 和 [v04-contract.yaml](../engineering/v04-contract.yaml)。

## 1. 已实现的范围

- 不可变 JSON MapPack，严格类型、完整字段、128KiB预算、来源声明与规范化摘要；固定320×192世界、2–8张地图和单出口循环路线。
- 实例级地图几何、出生点、地面怪物、NPC、门与梯子；外部目标交互有垂直交叠检查，边界梯子爬行后仍可保存恢复。
- 相同包用于场景渲染、可见标签、任务、生命周期数据与评估分组；策略只收路线ID和视觉观测，感知只获得静态地图标记表。
- 外部存档和数据集schema3，旧None路径schema1/2与旧RGB/状态/数据指纹保留。
- 运行包中三份地图元数据和感知设置绑定；无需原文件即可动作重放及N+1帧感知/策略重新执行。初始世界必须匹配声明的种子、职业参数与地图。
- 实际可执行CLI、三图样例、完整方案和独立验收脚本均在仓库内。

结构校验不保证任意用户地图一定可解，也不授予学习模型新地图准入。当前固定视口、单出口、地面怪物、既有三职业和有界策略限制详见[地图包合同](MAP_PACKS.md)。
