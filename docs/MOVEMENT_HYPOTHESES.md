# 录像中的运动状态候选

`recording track --movement` 在已有逐帧跟踪后增加只读几何判断。它帮助定位“靠近绳索、沿绳移动、接近平台并稳定下来”的证据，不授权输入，也不表示已经验证主角身份、抓绳动作或任务成功。

```sh
python -m maple_vision recording track artifacts/window-1200 --model artifacts/my-model/model.onnx --manifest artifacts/my-model/manifest.json --movement --output artifacts/window-1200-movement
python -m maple_vision recording verify-tracking artifacts/window-1200 artifacts/window-1200-movement --model artifacts/my-model/model.onnx --manifest artifacts/my-model/manifest.json
```

`--movement-config path.json` 接受完整的 `MovementConfig.to_dict()` 文档，并自动开启该分析；不需要另外指定 `--movement`。复验使用报告内的配置和算法版本，不能在复验时换门槛。没有这两个选项时，旧跟踪记录、窗口身份和叠加回放格式保持原样。没有提供模型时仍是合成色块感知，不代表真实录像识别。

## 四种输出

| 状态 | 必要证据 | 不能由此推出的结论 |
|---|---|---|
| `unknown` | 当前证据不足、矛盾、过期或不连续。记录具体原因。 | 没有人物、角色死亡或动作失败。 |
| `near_rope` | 唯一当前人物与当前绳索／梯子在几何上接近。 | 已经抓住绳索。 |
| `climbing_candidate` | 同一人物持续对齐同一绳索，扣除一致的地形平移后有足够纵向移动，横向漂移受限。 | 已确认攀爬。沿绳轴跳跃也可能产生这类候选。 |
| `platform_arrival_candidate` | 同一人物已有近期攀爬候选，随后脚部在同一平台上沿附近获得连续、稳定的相对位置支持。 | 物理接触已验证，或到达任务指定的上层平台。 |

这些状态是同一窗口内的几何假设。唯一可见人物不等于玩家自己的角色；画面中存在另一个人物检测，即使它的置信度不足以建立轨迹，也会使人物选择保持未知。人物丢失、重新关联、尺寸变化、身份歧义、源／epoch 改变、帧号断开、时间倒退或间隔过大，都会清除连续证据。

## 镜头、人物与地形

镜头补偿至少需要两个当前、匹配明确、框尺寸不变的地形轨迹，类别仅限 `platform`、`rope`、`ladder`。它们的平移必须相互一致；其他玩家、怪物、HUD 和背景不作为参照。所选绳索和到达平台本身也必须具备可用的当前几何关系。缺少参照或参照冲突时不会退回到直接解释屏幕速度。

人物位移取检测框下沿中点；绳索参照取其框中心。人物框尺寸变化会重置判断，避免动作姿态引起框中心变化时误报攀爬。地形与人物的框尺寸需要精确稳定，这是一项保守限制：检测抖动、缩放、视差、遮挡或绳端被裁切可能增加 `unknown`。几何门槛使用源图像像素和整数毫秒，默认值是工程参数，尚未按国服画面标定。

到达候选需要先有合格的攀爬证据。初始就站在平台上不会被记为一次攀绳到达；仅靠近平台上沿也不会立即建立稳定支持。支持丢失、平台改变、运动反向、绳索丢失或镜头参照失效会使相应证据失效。历史长度和攀爬到到达的时间间隔都有上限，超出预算会重置，不能截掉前因后仍宣称到达。

## 记录与复验

开启后，每个 `tracks.jsonl` 行增加 `movement`：候选状态、原因、人物／绳索／平台轨迹编号、脚部相对位移、镜头参照框及平移、证据源帧和算法版本。全帧均参与判断，GIF 仍只做有界抽样。

`report.json` 的 `movement_analysis` 保存完整配置、算法版本和各状态帧数；它们也参与窗口身份绑定。叠加回放显示候选状态和原因。`verify-tracking` 从原像素重新运行感知、跟踪、运动判断和绘图，比较完整逐帧结果；修改状态后仅重算 JSONL 哈希仍然不能通过。

输出始终为 `read_only=true`、`actionable=false`、`action_execution=none`。运动模块不会修改输入 belief；detector-only 的地图、资源信息和可行动权限不会因出现候选状态而提升。

## 当前验证范围

独立工程用例覆盖持续攀爬与稳定到达、镜头单独滚动、镜头跟随人物、多人和低置信度竞争框、旧轨迹、参考地形不一致、姿态尺寸变化、初始站立、证据过期和窗口不连续。另有从独立绘制像素导入录像、检测、跟踪、运动判断、叠加回放到完整复验的测试。

真实Ⅱ录像目前的事件边界和玩家确认见[实录记录](../reports/recording-reviews/2026-11-27-dead-forest-ii/README.md)。事件时间、人工几何草稿和模型预测分别保留，不能把人工标注作为模型输出后计算识别准确率。尚需完成连续人物／地形标注、独立检测评测和状态事件误差评测。重复执行得到相同候选状态不等于真实域准确性通过。
