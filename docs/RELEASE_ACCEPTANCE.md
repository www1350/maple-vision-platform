# v0.1 离线平台交付验收

验收范围是可在自己电脑上复现的离线研究平台：本地知识与素材、数据集、训练/推理、独立模拟器、多职业任务、故障与重放。规则、地图和训练场景均为项目自建 fixture。完整 v8 的真实域验收没有据此获得通过。

## 交付内容

- 可安装 Python 3.12 包、命令行、Windows/Linux CI 和隔离 wheel 检查。
- v2 知识库、不可覆盖的来源记录、冲突保留、快照与哈希验证；默认只使用 VERIFIED。
- 三职业的完整合成 ClassSpec 可由目录加载到模拟器和策略，保存为可独立重放的 v2 状态；不依赖源数据库继续在线。
- 授权静态 RGBA 素材从注册表进入场景和自动标签，透明度参与遮挡；缺省图像和既有数据集保持兼容。
- 18 会话、288 帧的训练实验；会话级 train/val/test，训练不修改来源数据。
- 随仓库交付 tiny YOLO ONNX 模型，CPU 推理并校验模型 manifest。
- 两图、三职业任务；跳标、范围攻击、自疗、药品、Buff、拾取、NPC 对话和地图切换。策略只读取图像观测。
- 短暂/持续黑屏、重复帧、输入丢失等故障，有限恢复、停止与失败包。
- 本地 PNG/MP4 录像导入和感知回放，以及有边界的本地 Tesseract OCR。录像不能验证未实际发生的操作结果。

## 已实测模型结果

只用验证集在 160px/30 epoch 和 320px/60 epoch 两个候选间选模；两项训练配置同时改变，不把提升归因于单一变量。最终选择 320px 检查点。

| 64 帧测试集指标 | 实测 |
|---|---:|
| 目标数 / TP / FP / FN | 633 / 535 / 0 / 98 |
| micro precision / recall | 1.0000 / 0.8452 |
| macro AP50，confidence≥0.25，IoU=0.5 | 0.92645 |
| 本机 CPU detect p50 / p95 | 16.65 / 40.94 ms |

这是截断 AP50，不能冒称完整 COCO mAP50–95。原始七类检测中的平台召回率约 0.4948，属于已知短板。闭环明确采用 YOLO 动态对象加合成场景像素地形/HUD；动态目标没有调色板回退。模型混合闭环的标飞/龙骑/牧师分别完成 327/349/317 步，均消灭六个目标、收集六个掉落、完成两图对话；标飞包含两次跳跃攻击。每个结果都通过独立真值校验和动作重放。

对应 [模型评估](../reports/release-0.1.0/yolo-benchmark.json)、[混合任务](../reports/release-0.1.0/yolo-missions.json)、[训练记录](YOLO_EXPERIMENT.md)。示例模型和 manifest 在 `examples/fixture-model/`，可直接用于 `lab run`，无需先训练。

## 独立审查中发现并修复的问题

1. 旧帧、重复帧与未来帧可能污染恢复序号或虚报效果：现在检查序号、捕获时间与处理时间，未知结果不计成功。
2. 模型文件在哈希校验后被替换：原生会话加载同一份已校验字节。
3. SQLite WAL 未进入快照哈希却能改变查询结果：快照规范化为独立文件，拒绝旁路日志并检查同一份字节。
4. v1 表重命名可能破坏既有外键/视图：有依赖扩展时原子拒绝，保留原库。
5. 重放报告可以错误声称任务完成、或截图与轨迹不一致：从动作重新计算状态、目标与采样像素，不只校验文件哈希。
6. Ultralytics 标签缓存污染数据集：训练使用校验过的私有副本，不降低数据完整性规则。
7. 跳标后追逐地面目标误入高台：加入落地等待和有界下台流程。
8. 原生 ONNX Runtime 初始化遥测尝试外联被自动审批拦截：已在导入前设置进程级禁用变量，并关闭 API 遥测；有导入顺序回归测试，重新完成本地推理。
9. Ultralytics 导入改写 Pillow 的全局 `Image.open`，使后续图像读取进入额外 HEIF 插件加载路径：在依赖导入完成后立即恢复调用方加载器，部分导入失败和操作异常时同样恢复。两项回归覆盖恢复时机与异常路径，修复后的训练、录像和 OCR 联合 107 项实际通过。

## 不得扩大解释的边界

- 小册子实时采集、真实素材/地图/技能校准、独立真实录像准确率都没有伪造为已完成；目录支持接收经授权的本地导出。
- 只支持列明的三个职业样例、两张内置地图及相应参数注入；不宣称已覆盖正式游戏全部职业、地图、动画和任务。
- Tesseract 实测只覆盖本机 eng/osd 及自写英文数字文本，没有中文游戏 OCR 准确率结论。
- 60 秒墙钟 smoke 与大量加速模拟均不等于 24 小时长稳；24 小时门禁保持未完成。
- 运行时没有 LLM API、聊天发送、操作系统按键或正式游戏控制后端。回复是本地待人工确认的草稿。
- 独立模拟器和离线验证不能证明正式账号不会被封。
