分层报告的 50 项专项还覆盖实际 MP4 生成、采样表/媒体偏移、相同解码器逐帧哈希、来源删除和语义篡改；视频始终标为有损展示，`video.semantic_reproduction=false`。权威 RGB 和动作可以独立重建，默认校验不会声称已重新感知。策略提前声称 completed 而 oracle 判失败的实际 0 动作/1 帧反例也能原样归档，未改写其终止决策。

## 独立发现与修复

- 旧数据 schema 只用 `exists()` 检查动画侧文件，悬空链接会被漏掉。两个独立反例已修复，旧数据拒绝未声明动画证据。
- 单纯动作 replay 原先没有核对轨迹和终态中的静态职业包身份。六处实际篡改并重算外层哈希后仍能通过的反例已保存；现在 state、decision、last_decision、interruption 的 class_id 和包哈希都与嵌入规则绑定。旧无包路径不能夹带该身份。真正的 belief/决策重计算仍由 reinfer 完成。[修复前六个失败](../reports/release-0.6.0/capability-identity-before-fix.log) · [永久回归](../tests/test_content_cli.py)
- 分层包严格区分“策略 completed”与“独立目标 failed”，允许真实失败覆写但必须由重放 oracle 证实，防止为了报告一致而丢失失败事实。
