## 可复验文件

`window-coverage.json` 绑定三个连续窗口：0–1,199、1,200–2,399、2,400–3,031。各窗口保留原视频时钟 1/600 秒、视频流编号 1、边界像素哈希及会话身份。三份可见事件报告共有 7 个区间；重叠事件数量不代表施放次数或完整标注帧数。

`evidence-ledger.json` 为新的独立账本。真实录像栏引用本目录；合成机制、演示键位和耗镖栏原样引用历史归档，不因这段实录得到真实域校准。旧死亡之林Ⅰ账本及其 15 段待审队列保持历史状态。

```sh
python -m maple_vision lab verify-trial-evidence reports/recording-reviews/2026-11-27-dead-forest-ii/evidence-ledger.json --root .
```

校验器会重新核对报告文件身份、覆盖链和事件来源，同时重放并重推理历史合成归档。它不验证本目录的用户陈述是否真实，也不读取当前未入库的原片像素；`raw_pixels_reverified=false` 必须保留。用户持有的复核包还包含完整导入 manifest 和四张边界帧，完整原片仍需由原视频恢复。公开仓库不包含录像或桌面 PNG。
