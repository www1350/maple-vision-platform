## 可复验文件

`window-coverage.json` 绑定三个连续窗口：0–1,199、1,200–2,399、2,400–3,031。各窗口保留原视频时钟 1/600 秒、视频流编号 1、边界像素哈希及会话身份。三份可见事件报告共有 7 个区间；重叠事件数量不代表施放次数或完整标注帧数。

`evidence-ledger.json` 为新的独立账本。真实录像栏引用本目录；合成机制、演示键位和耗镖栏原样引用历史归档，不因这段实录得到真实域校准。旧死亡之林Ⅰ账本及其 15 段待审队列保持历史状态。

```sh
python -m maple_vision lab verify-trial-evidence reports/recording-reviews/2026-11-27-dead-forest-ii/evidence-ledger.json --root .
```

校验器会重新核对报告文件身份、覆盖链和事件来源，同时重放并重推理历史合成归档。它不验证本目录的用户陈述是否真实，也不读取当前未入库的原片像素；`raw_pixels_reverified=false` 必须保留。用户持有的复核包还包含完整导入 manifest 和四张边界帧，完整原片仍需由原视频恢复。公开仓库不包含录像或桌面 PNG。

## 下一步实现

单窗口的跨帧跟踪已接入 `recording track`，能保存每帧轨迹与 belief，并通过 `verify-tracking` 从像素重建核验。可选的 `--movement` 进一步输出镜头补偿后的近绳、攀爬候选、平台到达候选及未知原因；详见[运动候选说明](../../../docs/MOVEMENT_HYPOTHESES.md)。这些工程进展没有改变本目录的历史视觉复核范围，也没有提供真实模型或状态准确率。

2026-11-28 从此前保存的证据包恢复源帧 2228、2231、2294、2295；四张 PNG 与 RGB 哈希均与完整导入 manifest 一致，未重新解码原视频。新增 [geometry-draft.json](geometry-draft.json) 记录这四帧两名中央人物的大致包围框、暴露绳段和目标平台雪面。两组对应帧的平台表面均在屏幕中向下移约 104 像素，说明必须考虑镜头平移。角色对应依赖人工观察标记，部分身体被遮挡，雪面也不等于碰撞边界，故这些只属于局部几何草稿。

连续目标 2220–2304 共 85 帧中，目前只有上述 4 帧补了几何草稿，其余 81 帧尚无几何草稿；历史的 85 帧视觉复核不能替代这项标注。下一步需要补齐连续人物／绳索／平台标签、独立检测评测和状态事件对照。遮挡、身份不明和缺少可靠地形时继续保留未知。用户已经确认本段地图、主攻技能和键位延续性，后续不应再把这三项列为等待用户补充的数据。

工程现已增加 [运动候选与人工复核对照](../../../docs/MOVEMENT_EVALUATION.md)：支持部分帧复核、明确正负例、人工不确定、程序弃权、人物框匹配及逐帧误差清单。它要求完整的导入像素及独立状态标签；现有四帧草稿没有自动转为合格标签，三个 manifest 也不能恢复其余像素。当前未对本录像执行这项评分，没有新增状态准确率或实机结果。既有多人保守判断会产生未知，需要后续显式人物选择与独立身份验证能力，不能通过挑选一名人物或删掉未知帧来掩盖。
